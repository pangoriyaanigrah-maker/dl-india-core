Picking a file does not upload it. Choose the holdings file, the trades file, or both, then click below: the backend validates, imports and reports exactly what changed.
Division of labour: analysts own weights, targets, theses and entry/exit strategy (holdings file); dealers own executions (trades file); market data — price, market cap, valuation, momentum, quality — is fetched by the app, not typed.
Signal feed is live: a GitHub Actions cron (build_signals.py) hits Yahoo Finance nightly for prices, momentum and fundamentals, computes z-scores across the constituents of the benchmark index (NSE's own list, re-fetched each run), and writes signals.json. Re-uploading a holdings file here replaces weights/targets/theses only — it does not touch the signal feed.
Saving is manual, on purpose. Picking a file writes nothing; Save Permanently is the one action that uploads it — with a confirmation naming exactly what's about to happen. There is deliberately no delete button in the app; delete the files in the Google Drive folder directly to wipe the book.
